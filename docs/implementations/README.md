# Independent implementations

This section records independently maintained interpreters and toolchains that read, execute, inspect, convert, or package DAAD material. They are **not** DAAD derivatives merely because they support DAAD databases or target media. Each implementation has its own source, version, compatibility boundary, input/output claims, and verification record.
