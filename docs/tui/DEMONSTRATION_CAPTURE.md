## Reproduction

Run the capture from a real retained state database:

```bash
python scripts/capture_tui_demo_gif.py \
  --db .audit/fetch-active-source-samples/state.db \
  --output docs/assets/tui-live-demo.gif \
  --width 132
```

> **Evidence rule.** The recording must not be regenerated from inserted sample games, mocked reviews, or invented detection results. An empty verified-DDB count remains visible whenever the chosen real audit state does not substantiate a verified payload.
