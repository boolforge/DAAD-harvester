# Public DAAD catalog source findings

Accessed 2026-08-22 from the repository work session.

## Sources

- Official DAAD repository: https://github.com/daad-adventure-writer/daad
  - README identifies targets: Commodore 64, Plus/4, ZX Spectrum, Amstrad CPC, MSX, PCW, Atari ST, Amiga, and IBM PC/DOS.
  - README describes DAAD as a compiler producing platform-specific game databases for target interpreters.
  - README states the public-domain contribution applies to the DAAD system; interpreter sources are not provided.
- CASA / Solution Archive DAAD catalog: https://solutionarchive.com/list/system%2C34/
  - Page title reports 95 DAAD results.
  - The page provides title, publisher, year, language, and document fields. It is catalog/discovery evidence only; it does not prove that bytes are publicly downloadable or authorized for redistribution.
- MSX.org historical release report: https://www.msx.org/news/en/multi-platform-daad-adventure-writer-v2-r2-released
  - Reports that the preservation files contained masters for five MSX games: Aventura Original, Jabato, Aventura Espacial, Chichen Itza, and Templos Sagrados.
  - This is a secondary source and must be cross-checked against retained bytes and primary release metadata.
- Interactive Fiction Community discussion: https://intfiction.org/t/old-adventure-creation-system-brought-back-to-life-daad/13553
  - Contains first-person historical context and mentions later DAAD-produced games such as Hibernated; treat as discovery evidence until independently corroborated.

## Boundary

No game was downloaded or added to the corpus from these findings alone. Candidate additions require a registered source, explicit release/platform/version boundary, license or authorization status, acquisition result, exact hash when bytes are obtained, and a catalog-only versus byte-measured evidence grade.
