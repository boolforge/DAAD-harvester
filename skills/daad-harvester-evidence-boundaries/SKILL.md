# Evidence boundaries

Treat filenames, extensions, archive labels, catalog claims, screenshots, and third-party outputs as context rather than binary identity. Promote a claim only when the relevant profile contract, retained bytes, native validator, provenance, positive test, rejection/corruption test, and real-artifact regression support that exact claim. Keep unknown, blocked, catalog-only, derived, runtime-observed, and structurally validated states distinct.

For every change, record the input identity, platform/profile, byte or state boundary, command, output hashes, non-claim, and unresolved blocker. Preserve original bytes unchanged and keep derived previews, decompilations, captures, and reports separately linked. Regenerate only through repository-native commands. Never mark a broad TODO requirement complete because one profile or child artifact passes.
